# Aisixteen Fantastic

*A medium that unifies humans and AIs into a single workspace.*

Fantastic is a kernel of agents. A model, a program, a file tree, a shell, a browser canvas and the human at the keyboard are all agents in one tree, addressed by id and reached the same way: one call, `send`. The protocol is the API: every agent answers `reflect` with what it is, and `docs` says how to call it.

- **Install:** `cargo install fantastic --locked`, or a prebuilt binary for macOS, Linux and Windows from the [latest release](https://github.com/aisixteen/fantastic/releases/latest)
- **Website:** [aisixteen.com/fantastic](https://aisixteen.com/fantastic/)
- **Source:** [aisixteen/fantastic](https://github.com/aisixteen/fantastic) · AGPL-3.0-or-later
- **Roadmap:** [the board](https://github.com/orgs/aisixteen/projects/1) · [from the app to fantastic OS](https://github.com/aisixteen/fantastic/issues/57)

## Where it's going

| Milestone | What it brings |
|---|---|
| **M1** App MVP | The manager of your fantastics as a desktop app |
| **M2** Cross-platform app and the reskin contract | Tauri on macOS, Windows and Linux; one UI, many skins |
| **M3** fantastic OS: kiosk | A Debian machine that boots straight into fantastic |
| **M4** fantastic OS: system agents | Network, audio, power and displays as agents |
